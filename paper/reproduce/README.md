# 精确复现材料

`verify_exact.py` 从原始相位、末位 Hadamard 门和 CNOT 链重新计算，不读取本目录之外的研究文件。使用 Python 3.11 以上及 SymPy；已运行版本为 Python 3.12.10、SymPy 1.14.0。

```text
python verify_exact.py
```

缺少 SymPy 时再按 `requirements.txt` 安装。不要使用会禁用断言的 `python -O`。程序生成 `verification_results.json`；可用 `--output 路径` 指定位置，随包保留已通过的计算结果 JSON。

| 论文内容 | 精确复算 |
|---|---|
| 统一构造 | 四特征分段式与三次式；六个固定 Walsh 和；n=5 至 10 的全参数 Laurent 种子恒等式与支持数 |
| Boolean 直线界 | n=2、3、4 原门拉回及解析排除所需字符方程 |
| 偶数母族 | 六个条件字符和；n=2、4、6、8 的原偶数轴；n=8、10 的二维恒等式；n=6 混合项与十八个四颜色/独立零点公式 |
| 低维结构 | 三比特 Jacobian 子式 1/4096；四比特完整核、二三阶障碍与两个充分平面 |
| 四比特曲线 | 十二个局部分量恒等式、半角二次式、全矩形符号证书和端点 |
| 不等价证书 | 前作相位表的实际局部分量和两体纯度；两个必要多项式及 resultant 的精确值 21153523695616 |
| 完整测量 | 四比特曲线相位模型及五比特统一族的全部 1280 个 Gram 元素、224 个真实偏迹矩阵的 Laurent 恒等式 |

四比特完整测量检查保留两个独立相位，先得到 H/T 两类分量，再施加曲线方程。计算使用精确整数、Gaussian 整数、分数及 SymPy 代数运算；程序中的复数仅承载可精确表示的小整数系数，没有相位采样或浮点误差阈值。

有限维复算核对公式与约定；任意维数及连续区间的结论由论文证明和对应 Lean 定理承担。计算固定首位为最高有效位，门从右至左作用，仅末位 Y 分量变号；相位修正只删除物理全零串。
